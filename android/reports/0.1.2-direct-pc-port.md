# Android direct port of PC 0.1.2

Upstream PC source: `sciaschi/CBFD-Recompiled@152cc380386481f008b40fb8c2059fd9a6fddedc`.

## Purpose

Reset the Android implementation to PC 0.1.2 behavior instead of continuing the
0.1.7–0.1.15 Android rendering experiments.

## Source changes

Shared PC files changed by the upstream 0.1.2 release were copied directly from
upstream, including the new widened level culling scale. Critical shared files are
locked in CI by their upstream Git blob IDs.

The Android build no longer compiles GLideN64, the orbital camera, the Android
frustum override or the custom render-policy sources. The dependency patcher applies
only cross-compilation/SDL support and the Android Vulkan WSI patch.

## Interface

The launcher now stays visible like the PC launcher rather than auto-starting when
a ROM exists. It exposes Start/Load, Version, Add ROM, Controls, Settings, Mods and
Exit. Graphics choices use RecompFrontend option meanings/defaults and are mapped to
RT64 using the same logic.

## Pending device validation

No claim is made yet about water, vegetation, performance, suspend/resume or a full
playthrough on the Samsung SM-A155M. CI is not a phone/GPU gameplay test.
